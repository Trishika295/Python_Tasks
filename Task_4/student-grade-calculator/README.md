# Student Grade Calculator

A clean and responsive Student Grade Calculator built with React and Python Flask. The application accepts marks for multiple subjects, validates the input, calculates total marks and percentage, and automatically assigns a grade based on predefined criteria.

# Features
-- Student name input
-- Marks input for multiple subjects
-- Input validation for marks between 0–100
-- Automatic total marks calculation
-- Percentage calculation
-- Automatic grade assignment
-- Subject-wise performance summary
-- Visual progress indicators
-- Clear validation and error messages
-- Reset functionality
-- Responsive and professional UI
-- React–Flask REST API integration

# Installation
1. Clone or download the project
   Open the project folder in VS Code.

2. Install Python dependencies
   Open a terminal inside the project folder:
   pip install -r requirements.txt

3. Install React dependencies
   npm install

4. Start the Flask Backend
   In the first terminal: python app.py
   In second terminal: npm run dev
