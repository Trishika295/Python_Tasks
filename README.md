# Even & Odd Number Checker

A simple and interactive Even & Odd Number Checker built with React.js for the frontend and Python Flask for the backend. The application uses the modulus (%) operator to determine whether a given integer is even or odd.

# Features
--Check whether a number is Even or Odd
--Supports negative numbers
--Handles zero correctly
--React-based interactive interface
--Python Flask backend
--REST API communication between frontend and backend
--Input validation for invalid values
--Press Enter to check a number
--Clear button to reset the result
--Quick example buttons for easy testing
--Responsive and clean interface

# Installation & Setup
1. Clone the repository
   git clone <https://github.com/Trishika295/Python_Tasks.git>
2. Navigate to the project
   cd even-odd-checker
3. Install Python dependencies
   pip install -r requirements.txt
4. Install frontend dependencies
   npm install
5. Running the Project
   python app.py
   npm run dev
