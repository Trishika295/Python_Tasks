# Objective

The objective of this project is to develop a simple task-management application that demonstrates:
--Python lists and functions
--Loops and conditional statements
--CRUD operations
--Menu-driven programming
--REST API development
--React frontend development
--Frontend-backend integration
--JSON-based data storage

# Features
--Add new tasks
--View all tasks
--Edit existing tasks
--Mark tasks as completed
--Change tasks between completed and pending
--Delete tasks
--Display total, pending, and completed task counts
--Display overall completion percentage
--Store task data in tasks.json
--Python command-line interface
--React web interface
--REST API communication
--Input validation and error handling
--Confetti celebration when all tasks are completed
--Responsive user interface

# Technologies Used
Frontend: React.js, HTML5, CSS3, JavaScript, Vite
Backend: Python, Flask, Flask-CORS
Communication: REST API, Fetch API, JSON
Storage: JSON file (tasks.json)
Version Control: Git, GitHub

# Installation and Setup
1. Clone the Repository
git clone <your-repository-url>
Navigate to the project:
cd Task_8/todo-list

2. Set Up Python Environment
Create a virtual environment: python -m venv venv
Activate it on Windows: venv\Scripts\activate
Install the required Python packages: python -m pip install -r requirements.txt

3. Install React Dependencies

Run:npm install
Ternimal 1: python app.py
Terminal 2: npm run dev
Terminal 3: python app.py cli (optional)
