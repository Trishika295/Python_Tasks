# Palindrome Checker

A simple Python mini-project that determines whether a word or sentence is a palindrome.

## Objective

The objective of this project is to practice Python string manipulation and comparison logic by checking whether a word or sentence reads the same forward and backward.

The program normalizes the input by converting it to lowercase and removing unnecessary spaces before performing the palindrome check.

## Features

- Accepts words and sentences as input
- Converts input to lowercase
- Removes spaces
- Reverses strings using Python slicing
- Compares the normalized string with its reversed version
- Displays the original, normalized, and reversed text
- Handles empty input
- Provides examples of valid and invalid palindromes

## Technologies Used

- Python
- Python String Manipulation
- String Slicing
