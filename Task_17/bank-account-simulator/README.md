# Task 17 - Bank Account Simulator

A simple menu-driven Bank Account Simulator developed using Python and Streamlit.

## Objective

The objective of this project is to build a simple banking simulator that supports balance inquiry, deposit, withdrawal, and transaction history.

The project focuses on practicing Python functions, loops, input validation, and application state management.

## Features

- Balance inquiry
- Deposit money
- Withdraw money
- Transaction history
- Balance calculation
- Input validation
- Prevents withdrawals greater than available balance
- Stores transactions in a Python list
- Menu-driven Streamlit interface
- Session-based state management

## Technologies Used

- Python
- Streamlit
