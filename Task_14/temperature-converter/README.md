# Temperature Converter

A simple Python command-line application that converts temperatures between Celsius, Fahrenheit, and Kelvin.

## Objective

The objective of this project is to practice Python functions, arithmetic operations, input validation, conditional statements, and formatted output by developing a temperature conversion program.

## Features

- Convert Celsius to Fahrenheit
- Convert Celsius to Kelvin
- Convert Fahrenheit to Celsius
- Convert Fahrenheit to Kelvin
- Convert Kelvin to Celsius
- Convert Kelvin to Fahrenheit
- Validate numeric input
- Validate physically meaningful temperatures
- Display results with two decimal places
- Interactive command-line menu
- Separate reusable conversion functions

## Technologies Used

- Python 3
- Python Standard Library
