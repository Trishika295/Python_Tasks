# Prime Number Analyzer

A Python-based command-line application that checks whether a number is prime and generates all prime numbers within a specified range.

## Objective

The objective of this project is to practice:

- Python loops
- Conditional statements
- Functions
- Mathematical logic
- Basic algorithmic thinking
- Algorithm optimization

## Features

- Check whether a number is prime
- Generate prime numbers within a specified range
- Reusable `is_prime()` function
- Optimized divisibility checking
- Handles edge cases such as 0 and 1
- Handles negative numbers
- Handles reversed ranges
- Displays algorithm explanation
- Displays time and space complexity
- Interactive command-line interface

## Technology Used

- Python

No external libraries or frameworks are required.
